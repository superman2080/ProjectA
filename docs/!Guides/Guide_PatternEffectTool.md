# Guide — Pattern Effect Tool (패턴별 월드 이펙트)

`Tools/Pattern Effect Tool`

패턴 에셋이 소유한 **월드 이펙트 큐**를 편집·저장하는 창. 이펙트는 Canvas가 아니라 3D 공간에 뜨며,
**패턴 진행 중 임의의 시점 · 임의의 부착 지점**에 붙는다.

---

## 1. 한 줄 요약

> 큐 하나 = "**언제 · 어디에 · 어떤 조건에서** 이 프리팹을 재생할지".
> 패턴 하나에 큐를 몇 개든 넣는다.

---

## 2. 창 구성

| 영역 | 하는 일 |
|---|---|
| 상단 툴바 | **저장** · 패턴 새로고침 · 재생/정지 · **시간축 가정**(노드 간격 / 노출 / Good창) |
| 프리뷰 | 애니메이션 + 파티클을 **같은 t로** 굴린다. 좌드래그 회전, 휠 줌 |
| 타임라인 | `start → n0 · n1 … → last → impact` 축 위에 큐 마커. 드래그로 스크럽 |
| 좌측 목록 | 템플릿 폴더의 패턴들(`● n` = 큐 n개) |
| 중앙 리스트 | 큐 추가/복제/삭제/순서 변경 |
| 우측 상세 | 선택한 큐의 모든 값 |

**시간축은 임팩트가 0인 상대시간**이다(`Animation Clip Trimmer`와 같은 규약).
노드 간격은 곡마다 다르므로 **가정값**이며 툴바에 그대로 적혀 있다 — 시각 계산 자체는 런타임과 같은 함수를 쓴다.

---

## 3. 큐 값

### 언제 (`condition` + `timing` + `timeOffset`)

**조건은 적이 재생하는 반응 클립을 따라간다** — 판정 결과가 아니다.

| `condition` | 언제 뜨나 | 화면 사실 |
|---|---|---|
| `Always` | 성패와 무관 | 기 모으기, 칼날 잔광 |
| `Success` | 완주 성공 | `Attacker.Player`면 벤다 / `Attacker.Enemy`면 받아쳐 밀어낸다 |
| `Parry` | 실패 + 적이 **제자리에서 막음** | **칼이 맞부딪힌다** (스파크) |
| `Evade` | 실패 + 적이 **물러남** | `Attacker.Player`면 헛스윙 / `Attacker.Enemy`면 플레이어 피격 |

> **뒷구르기(Evade)에 이펙트가 없어야 하면 큐를 만들지 않는다.** 코드 분기가 아니라 저장의 문제다.
> `Attacker.Enemy` 패턴에서는 `Parry`가 드롭다운에 아예 안 뜬다(그 역할에선 적이 막지 않는다).

`timing` 기준점 다섯: `PatternStart` / `FirstNode` / `Node[i]` / `LastNode` / `Impact`.
여기에 `timeOffset`(±초)이 더해진다.

> ⚠ **결과 조건(`Success`/`Parry`/`Evade`) 큐는 `LastNode`보다 이른 시각에 걸 수 없다.**
> 성패가 거기서 정해지기 때문이다. 걸면 타임라인 막대가 **빨갛게** 되고 런타임은 조용히 폐기한다.

### 어디에 (`anchor` + `follow`)

| `anchor` | 기준 |
|---|---|
| `ImpactAnchor` | 칼이 지나가는 지점 — **플레이어의 자식**, BattleScene 기준 로컬 `(0, 0, 1)`(발밑 높이 1m 앞) |
| `Player` | 플레이어 루트 |
| `PlayerWeapon` | 칼날 노드 — `bladeT`로 날 위 한 점 |
| `Opponent` | 지금 교전 중인 상대 |

- **`follow`** = 앵커의 자식으로 붙어 따라간다(칼날 잔상). 끄면 발사 순간 포즈만 복사해 월드에 남는다(스파크).
- **`bladeT`**: 0 = 손잡이 쪽, 1 = 칼끝. **길이가 아니라 비율**이라 무기를 바꿔도 칼끝은 칼끝이다.
- **`alignToBlade`**: 회전을 칼날 축 + 진행 방향에 맞춘다. 이 옵션을 쓸 때만 매 프레임 비용이 생긴다.

### 재생 (`scale` / `speed` / `poolSize`)

- `speed`는 파티클 `simulationSpeed`다. **지속시간도 함께 줄어든다**(타임라인 막대가 그만큼 짧아진다).
- `poolSize`는 미리 확보할 개수. **곡 도중 `Instantiate`는 히치 = 판정 손실**이므로 반드시 채운다(§5).

## 3-1. 저장

값을 만지면 **툴바 저장 버튼에 `*`가 붙고 창 제목에도 표시**된다. 그 시점에 값은 이미 에셋(메모리)에 들어가 있지만 **디스크에는 아직 안 적혀 있다**.

| 방법 | 결과 |
|---|---|
| 툴바 **`저장 *`** 버튼 | 그 패턴 에셋만 즉시 기록 |
| 다른 패턴으로 갈아타기 | 이전 패턴을 **자동 저장**한 뒤 넘어간다 |
| 창 닫기 | Unity가 "저장할까요?"를 묻는다 |
| Unity의 프로젝트 저장(`Ctrl+S`) | 더티 에셋과 함께 기록된다 |

> 창을 안 닫고 Unity를 강제 종료하면 기록되지 않는다 — 큐를 만졌으면 `*`가 사라졌는지 보고 넘어간다.

## 4. 칼날 경로에 붙이기

1. 우측 상세에서 `anchor = PlayerWeapon`, `follow = ✔`.
2. `bladeT`를 끌면 **프리뷰의 노란 폴리라인**이 그 지점의 궤적으로 다시 그려진다.
3. 궤적 위에서 **우클릭** → 그 프레임의 시각이 큐의 `timeOffset`으로 들어간다.
   칼이 표적을 스치는 지점을 찍으면 타이밍이 그 자리에서 정해진다 — 숫자를 손으로 맞출 일이 없다.
4. 칼날 전체에 깔고 싶으면 **큐를 복제해 `bladeT`만** 바꾼다.

> 흰 점 = 지금 `t`의 칼날 위치. 폴리라인이 안 보이면 플레이어 프리팹 / 칼날 노드 이름을 확인한다
> (같은 이름 노드가 2단이라 **메쉬가 달린 안쪽**을 잡아야 한다).

## 5. 씬 배선 (한 번만)

`BattleScene`의 **Main Camera**에 `PatternEffectDirector`가 붙어 있다.

| 필드 | 값 |
|---|---|
| `handler` | PatternHandler |
| `enemyDirector` | EnemyDirector (비우면 `Parry`/`Evade` 큐만 빠진다) |
| `impactAnchor` | ImpactAnchor |
| `playerRoot` | 플레이어 루트 |
| `playerWeapon` | `root/add_weapon_r/Weapon_Katana_01_Blade/**Weapon_Katana_01_Blade**` (안쪽) |
| `prewarmPatterns` | **곡에서 쓸 패턴들을 넣는다** — 여기 없으면 첫 재생 때 히치가 난다 |
| `effectsEnabled` | 전체 On/Off |

`HitStopDirector.patternEffectDirector`도 같이 배선돼 있다 — 그래야 **정지 창 동안 파티클도 언다**.

---

## 5-1. 소리 저작

큐 상세의 **소리** 섹션에 `sfx`(AudioClip) · `sfxVolume` · `sfxPitch`가 있다. **패턴별 임팩트음은 여기서 낸다** — `SfxManager` 카탈로그의 `SfxTrigger`는 키를 코드가 정해 패턴마다 다른 소리를 담을 수 없다.

- **소리 전용 큐**: 프리팹을 비우고 `sfx`만 채운다. 앵커·`follow`·`bladeT`·`poolSize`는 무시된다(소리는 2D라 위치가 없다). 목록에 `♪` 뱃지가 뜬다.
- **그림 + 소리 한 큐**: 둘 다 채우면 같은 시각에 같이 난다. 스파크와 챙 소리처럼 한 사건이면 이쪽이 낫다 — 큐를 나누면 `timeOffset`을 두 번 맞춰야 한다.
- **조건이 그대로 쓰인다**: `Success` 촥 / `Parry` 챙 / **`Evade`는 큐를 안 만들어 무음**(적이 뒷구르기 하는데 소리가 나면 안 맞는다).
- **⚠ 프리뷰는 소리를 재생하지 않는다.** 스크럽 되감기가 오디오에는 없어 매 프레임 소리가 튀면 저작을 방해한다 — 타임라인 막대(클립 길이)로 시각만 확인하고, 실제 소리는 플레이로 듣는다.
- **⚠ 소리 큐를 하나라도 만들면 공용 임팩트음(`SfxTrigger.PatternImpact`)이 이 패턴에서 물러난다.** 겹쳐 울리지 않게 하는 장치다. 즉 `PatternStart`에 칼 뽑는 소리만 넣으면 **임팩트가 무음이 된다** — 필요하면 `Impact` 타이밍 큐를 같이 만든다.

---

## 6. 자주 겪는 것

| 증상 | 원인 |
|---|---|
| 큐가 아예 안 뜬다 | 프리팹도 소리도 비었거나(정상적인 무연출), 결과 조건이 `LastNode`보다 이르다(타임라인이 빨갛다) |
| 소리 큐를 넣었더니 임팩트가 무음이 됐다 | 공용 `PatternImpact` 폴백이 물러났다. `Impact` 타이밍 소리 큐를 만든다(§5-1) |
| 소리가 두 번 들린다 | 소리 큐가 둘 이상 같은 시각에 걸려 있다. 타임라인에서 `♪` 막대가 겹치는지 본다 |
| 프리뷰에서 소리가 안 난다 | 정상이다 — 프리뷰는 소리를 재생하지 않는다(§5-1) |
| 스파크가 허공에서 튄다 | `Parry`가 아니라 `Evade`에 걸었다 — 회피는 칼이 안 닿는다 |
| 이펙트가 칼 옆구리로 나간다 | `playerWeapon`이 바깥(빈) 노드다. 안쪽 노드를 잡는다 |
| 프리뷰와 게임의 높이가 다르다 | `프리뷰 배우 > 임팩트 앵커`가 씬과 다르다. **씬에서 읽기** 버튼을 누른다 |
| 첫 재생에서만 끊긴다 | `prewarmPatterns`가 비었다 |
| 이펙트만 혼자 흐른다 | `HitStopDirector.patternEffectDirector`가 비었다 |
| 다음 큐가 이전 큐 배속을 물려받는다 | (없어야 정상) 풀 반납 시 원복한다 — 보이면 버그다 |
