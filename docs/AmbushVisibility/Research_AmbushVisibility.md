# Research — 기습 가시성 (AmbushVisibility)

## 증상

적 기습(§11-4 아님 — `DodgeDirector`의 회피 이벤트)이 **눈에 안 들어온다.**
추가로: 회피 노트가 **패턴 입력 창과 겹쳐서** 뜬다.

## 가시성이 깨지는 자리 넷

### 1. 발동 시점에 화면 안인지 다시 안 본다
`DodgeDirector.HandleIdleWindow:261`이 `IsVisible(stagedAmbusher)`로 후보를 거른다.
그런데 그건 **공백이 열리는 순간**이고, 실제 발동(`Fire:394`)은 `BusyReasonBy`만 재확인한다.

그 사이에 화면이 바뀔 수 있다:
- `CameraAngleSwitcher`가 앵글을 갈아끼운다(§7-5, 쿨다운 6초 · 블렌드 0.4초)
- 플레이어가 상대를 바꾸며 yaw가 돈다(`cameraTurnDamping` 0.45초)

→ **프레임 밖으로 나간 적이 기습한다.**

### 2. 화면 밖이면 닷지 포인트가 통째로 사라진다
`DodgePointView.UpdatePosition:117` — 카메라 뒤면 `SetVisible(false)`(스케일 0).
옆으로 벗어나면 캔버스 rect 밖 좌표라 **역시 안 보인다.**
즉 **유일한 타이밍 단서인 링이 없어진다.** 남는 단서는 적의 와인드업 모션인데 그것도 화면 밖이다.

### 3. 시선이 화면 중앙에 묶여 있다
패턴인풋은 `Point_5`가 **화면 정중앙**(§1)이고, 링·가이드가 상시 수축 중이다.
기습 단서는 **적의 월드 위치 = 화면 주변부**다. 0.4~0.8초짜리 신호를 주변시로 잡으라는 요구다.

### 4. 소리가 없다
`SfxCatalog.cs:8` — `SfxTrigger`는 `Perfect` / `Good` / `Miss` **셋뿐**이다.
기습 텔레그래프도, 회피 성공·실패도 **무음**이다.
`EffectTrigger`에도 기습 항목이 없고, §7-4 월드 이펙트는 **패턴이 소유**하는 큐라 패턴이 아닌 기습은 쓸 수 없다.

## 겹침 문제 (신규)

닷지 포인트는 적의 월드 위치를 화면으로 투영해 그 자리에 뜬다(`UpdatePosition`).
적은 결투 거리 ≈1~2.5m라 **화면 중앙 근처에 투영되는 일이 잦다** — 거기가 패턴인풋 영역이다.

| 요소 | 자리 | 크기 |
|---|---|---|
| 패턴 노드(Point) | 3x3, 간격 700px, 중심이 화면 정중앙 | 노브 90x90 |
| 패턴 포커스 링 | 노드 자리 | 180 → 90 (start scale 2) |
| **회피 닷지 포인트 링** | 적 투영 위치 | 450 → 90 (start scale 5, 씬 값) |

**끝 크기가 90으로 같다.** 색만 다르고(주황빨강 vs 팔레트) 크기·모양·수축 거동이 같으니
겹치는 순간 **어느 것이 회피인지 구분이 안 된다.**

⚠ 닷지 포인트 링의 `endSize`는 `FocusRing` 프리팹(90x90)에 있고 **패턴 링과 같은 풀**(`PoolKey.FocusRing`)을 쓴다 —
그 값을 키우면 패턴 링까지 커진다. 크기 차이는 **닷지 포인트 루트 스케일**로만 낼 수 있다.

## 타이밍 예산 (E안의 근거)

| 노브 | 값 | 성질 |
|---|---|---|
| `minRingExposure` | 0.4초 | 링 최소 노출. **후보 자격(`RequiredLead`)도 이 값을 쓴다** |
| `maxRingExposure` | 0.8초 | 링 최대 노출 |
| `dodgeWindow` | 0.15초 | 임팩트 이후 유예 |
| `minIdleWindow` | 0.6초 | 공백에 요구하는 최소 길이 |

`RequiredLead(clip) = max(와인드업, minRingExposure)`(`:329`) —
**노출을 늘리면 발동 가능한 공백이 함께 줄어든다.** 실측(`Dreamer_Lv10`): 공백 ≥0.6초가 83%, **≥0.8초가 25%**.
→ `maxRingExposure`를 올리는 것은 **가시성 ↔ 빈도의 맞교환**이고, `minRingExposure`를 올리면 빈도가 직접 깎인다.
